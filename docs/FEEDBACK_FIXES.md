This report tracks the user-supplied desktop issue list. It supplements the earlier device results; source coverage, native validation and physical acceptance are distinguished below. The supplied Xiaomi English patch and XiControl original codebase remain untouched. No Git, installs, driver updates or forced reboot were used.

## Meeting subtitles investigation

The supplied `PcControlCenter.dll` contains `MainViewModel.OpenSubtitleTranscription` and `MeetingAssistantService.OpenSubtitleTranscription`; `SubtitleTranscriptor.dll` contains the transcription/translation component. The managed command-line metadata confirms `--open_controlcenter`. No standalone subtitles executable or supported direct subtitles launch flag was verified. Toolbox therefore opens the original quick panel, where Subtitles Translation can be selected. This is a hosted OEM function, with account/cloud requirements documented by the [Xiaomi PC Manager privacy policy](https://privacy.mi.com/PCManager/zh_CN/), not the separate planned offline screen translator.

## Latest feedback and additional controls, September 28

This section supersedes the earlier appearance and quick-panel descriptions above. The latest deployed assembly is `02D9D2C393AAC1A056C4894BBCDF101AF709102AE4018A4CA42B10030798EB61`. Deployment/source hashes are preserved in [Audit 079](../results/079_20260928T045441967_feedback_audit/summary.json).

Settings now apply through their normal callbacks on committed changes, with serialized rapid edits. Text/numeric fields commit on change or blur; invalid JSON and incomplete shortcut drafts are retained. Manager Undo/Redo and Ctrl+Z/Ctrl+Y keep up to 32 in-memory edits. API settings, app launches, image bytes and brightness dragging are excluded. Presets initialize the accent and permit subsequent overrides. Defaults appear on a new help line. Vertical scrolling is enabled while horizontal scrolling is suppressed. Notifications uses a message icon, Home includes a performance icon, and the header adds Maximize/restore and plain refresh arrows.

The narrower panel has smaller icons and distinct compact/roomy geometry. Battery care is an active persistent toggle; disabling it requests persistent 100% charging. Its percentage remains manager-only. Travel remains a cancelable one-off override and is cleared at every resident startup, restoring care. Both firmware targets are verified rather than assumed. Charge estimates use remaining capacity and net battery charging watts, with no claim of accuracy near charge taper. The rate button cycles confirmed supported rates. Screen off requests display power-off without system sleep; normal sleep timers still apply unless Stay awake is enabled. Stay awake and tray residency are independent.

Outside clicks are handled by a hook installed only while the panel is visible. Activation loss alone no longer closes it, because changing display rates can temporarily transfer focus to Windows. Opening requests foreground focus, and placement follows the currently exposed taskbar edge with a visible-only timer. Short 120/110 ms opacity/translation animations have no idle loop, honor reduced-motion preference and can be disabled. App/tray assets use white outlines. Xiaomi dark English OSD artwork has white glyphs independently of the manager theme.
