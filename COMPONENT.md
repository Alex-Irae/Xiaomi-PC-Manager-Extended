# Screen Translator child of PC Manager

This branch starts from manager/main at PC Manager 0.2.0 and identifies the optional Screen Translator component. Shared source remains included so the connected and standalone editions can be built together.

Edit source/screen-translator and source/shared. See source/screen-translator/README.md and the root README for its private offline runtime, fixed Chinese-to-English model, script filtering, idle memory release and shared shortcut ownership.

After installation, edit Screen Translator/Development/source/screen-translator and run Screen Translator/Development/Launch.cmd. Screen Translator/ScreenTranslator.exe --tray starts the installed copy; it works with its own shortcuts when PC Manager is absent.
