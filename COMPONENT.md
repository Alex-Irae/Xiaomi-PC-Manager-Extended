# AI Center child of PC Manager

This branch starts from manager/main at PC Manager 0.2.0 and identifies the optional AI Center semantic file-search component. Shared source remains included so connected and standalone editions stay buildable.

Edit source/file-search and source/shared. See source/file-search/README.md and the root README for its private Python/OpenVINO runtime, model and index paths, recursive exclusions and shortcut ownership.

After installation, edit AI Center/Development/source/file-search and run AI Center/Development/Launch.cmd. AI Center/AI Center.exe --search opens installed search; --center opens its settings. AI Center works with its own shortcuts when PC Manager is absent.
