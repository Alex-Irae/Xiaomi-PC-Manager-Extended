Privacy

Protects indexed names, content and vectors at rest. Your signed-in account unlocks automatically. This does not encrypt original documents or protect against software running as you.

Index and backup

The index contains your file metadata, extracted text and embeddings. Backups preserve these together. Model weights and original documents are not copied.

Choose a folder outside application data, such as an external drive. This encrypted backup requires the original Windows profile keys; it is not a transfer to another PC or a new Windows installation. Wait for Backup complete before quitting AI Center.

Reset the index?
