Power and startup

Auto follows Windows power mode, with a battery fallback. Eco refreshes less often. All profiles skip unchanged frames and select validated hardware automatically.

Shortcuts synchronize with PC Manager when installed.

Choose from the list or press your combination in the recorder. Save settings to apply. A shortcut assigned to another app action swaps their keys automatically. Windows security shortcuts and keys reserved by other software are unavailable. Press again or Esc to dismiss.

Size is relative to the original text. Larger text can use nearby blank space, while adjacent text is protected. With fitting off, text that cannot fit is shortened with an ellipsis and amber indicator. High contrast uses a dark background at each original text position.

Screenshots

Save PNG in the floating toolbar writes the current translated screen or selected region, without the toolbar. Only this action saves screen content to disk.

Hardware

Compares available NPU, iGPU and CPU devices, then reuses the fastest successful choice for each stage. The first load takes longer for calibration.

Off by default: translation refreshes while you scroll or use another app. Enabled: leaving the toolbar shows the original; refresh continues in the background. Changed text clears immediately while unchanged replacements remain.

Changes are saved as you make them. Undo and redo are in the top bar.
Model provisioning

The packaged app already includes PP-OCRv4 recognition and OPUS Chinese-to-English translation. Verification reuses matching local files without downloading. Restoration fetches only missing files from Hugging Face, about 687 MB for an empty bundle. This is a fixed bundle, not a marketplace or model upgrade. Changed or corrupt files require a new writable bundle folder. Translation stays offline.

Engine and timing

Timings and device assignments are saved locally. Screen images and recognized text stay in memory unless you save a screenshot.
